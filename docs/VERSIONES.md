# Historial de versiones

## v1.0.0 — versión de pruebas

Versión preparada para una nueva ronda de SQA. Incorpora correcciones a las observaciones realizadas sobre el commit `db117ea` y mejoras posteriores.

- Ajustes a la comprobación de disponibilidad de MySQL.
- Validación de fechas y respuestas claras para datos duplicados, JSON inválido y solicitudes demasiado grandes.
- Retiro del selector de credenciales de demostración y mejoras en los mensajes de inicio y cierre de sesión.
- Nombres de residentes en referencias y citas cuando existe el registro correspondiente.
- Diagramas, manuales y actualización de seguimiento; pruebas automáticas adicionales.

Esta no es una versión final ni está autorizada para datos reales. Quedan pendientes la verificación automática entre referencias, residentes, visitas y liquidaciones, una nueva ejecución de pruebas SQA y las medidas necesarias para un despliegue seguro. El cronograma de Microsoft Project debe actualizarse con datos reales de ejecución.
